# Plan: Edit Row from Data View

- **Date:** 2025-07-16
- **Domain(s):** backend, frontend, database
- **Author:** plan-from-spec (reviewed with user)
- **Status:** Draft

## 1. Summary

Add a row-editing capability to the data view panel. When the user is focused on a table's data rows and presses `e`, a modal opens showing one text input per editable column, pre-filled with the current row values. On save, an `UPDATE` statement is issued using primary key columns (or all original values as fallback) in the `WHERE` clause. PostgreSQL is implemented first; MySQL, SQLite, and Oracle receive stub implementations.

## 2. Scope

### In scope
- `e` keybinding on the data panel to open an edit modal for the currently selected row
- A scrollable modal dialog with a labelled text input for each editable column
- Construction of a parameterized `UPDATE` SQL statement using PK columns for the `WHERE` clause
- Fallback to all-original-values `WHERE` when no PK is detected
- Identity/generated columns are displayed as read-only; all other columns are editable
- Empty input means `NULL`; blocked for `NOT NULL` columns without a `DEFAULT`
- New `UpdateRow(ctx, table, setMap, whereMap) error` method on `db.Database`
- PostgreSQL implementation of `UpdateRow`
- Stub `UpdateRow` returning `"not implemented"` for MySQL, SQLite, Oracle
- Column metadata extended with `IsPrimaryKey bool` (detected per-driver)
- Reload the current page after a successful update so the table reflects changes
- Inline error display when the database rejects the update
- Footer help text includes `e` when a row is selected in the data panel

### Out of scope / non-goals
- Editing rows in views or materialized views (views are skipped)
- Multi-row batch editing
- Inline cell editing in the table grid
- Undo / revert of individual fields within the modal
- Type-specific input widgets (everything is a text input; type conversion happens at the driver boundary)
- Editing with `JOIN` results or arbitrary query results (raw query panel excluded)

## 3. Resolved decisions

| # | Question | Decision |
|---|----------|----------|
| 1 | Trigger mechanism | Press `e` key when focused on data panel with a row selected |
| 2 | Edit UI style | Scrollable modal dialog with one text input per column |
| 3 | Row identification for WHERE | Primary key columns; fallback to all original column values |
| 4 | Which columns are editable | All non-identity/non-generated columns; PK columns are editable |
| 5 | Database interface approach | New `UpdateRow(ctx, table, setMap, whereMap) error` method |
| 6 | NULL representation | Empty input = NULL; blocked for NOT NULL columns without a DEFAULT |
| 7 | Engine scope | PostgreSQL first; MySQL, SQLite, Oracle get "not implemented" stubs |
| 8 | What happens after save | Reload current page to show updated data |
| 9 | PK detection | Add `IsPrimaryKey bool` to `db.Column`; each driver populates it in `ListColumns` |

## 4. Design

### Data model changes

**`db.Column`** — add one field:

```go
type Column struct {
    // ... existing fields ...
    IsPrimaryKey bool  // NEW
}
```

**`db.Database` interface** — add one method:

```go
UpdateRow(ctx context.Context, table Table, setColumns map[string]any, whereColumns map[string]any) error
```

- `setColumns` maps column name → new value (nil means NULL)
- `whereColumns` maps column name → original value (nil means NULL)
- The driver constructs a parameterized `UPDATE "schema"."table" SET col1=$1, col2=$2 WHERE pk1=$3 AND pk2=$4` query

### New app-layer types

**`editRowModal`** — follows the pattern of `actionsModal`, `ddlModal`, etc.:

```go
type editRowField struct {
    column   db.Column
    input    textinput.Model
    original any     // original value from the row
}

type editRowModal struct {
    tableName  string
    fields     []editRowField
    selected   int        // which field is focused
    offset     int        // scroll offset for fields
    loading    bool
    err        error
    state      editRowState  // editing | saving | success | failed
}
```

### Component architecture

```
Model
├── navigator (unchanged)
├── data panel (unchanged)
├── query panel (unchanged)
└── editRowModal  ← NEW
```

The `editRowModal` follows the exact same lifecycle pattern as `actionsModal`:
- Created and stored in `Model.editRowModal *editRowModal`
- Rendered as an overlay via `renderModalOverlay()`
- Key events captured in `updateEditRowModal()`
- Async save via `tea.Cmd` → message → `updateLifecycle`

### Keybinding

Add to `keyMap`:

```go
editRow key.Binding  // key.WithKeys("e"), key.WithHelp("e", "edit row")
```

Only active when: `m.panel == panelData && m.focus == focusData && m.activeRelation.set && len(m.data.page.Rows) > 0 && !m.data.loading`

### Row identification — PK fallback strategy

1. At edit-modal-open time, the app reads `m.data.page.Rows[m.data.selected]` to get the original values
2. It calls `m.database.ListColumns(ctx, table)` to get column metadata (already implemented)
3. It identifies PK columns via `column.IsPrimaryKey`
4. If ≥1 PK column exists → `WHERE` uses only PK columns
5. If no PK → `WHERE` uses all columns (excluding identity/generated columns)
6. PK columns are presented as editable fields in the modal (user can change PK values; the WHERE uses the **original** PK values, not the edited ones)

### NULL representation

- When the current value is `nil` (SQL NULL), the text input shows `(NULL)` as placeholder and starts empty
- When the user clears a text input, it maps to `nil` (will become NULL in the UPDATE SET)
- If the column is `NOT NULL` and has no `Default`, clearing the input is rejected with an inline validation error
- If the column is `NOT NULL` but has a `Default`, clearing passes and the DB applies the default

## 5. Interfaces & contracts

### `db.Database.UpdateRow`

```
UpdateRow(ctx context.Context, table Table, setColumns map[string]any, whereColumns map[string]any) error
```

**Inputs:**
- `table`: the table to update (Name is the unqualified table name)
- `setColumns`: map of column name → new value. nil value = SQL NULL.
- `whereColumns`: map of column name → original value. nil value = SQL NULL.

**Output:** `error` or `nil` on success.

**Behavior:**
- PostgreSQL: builds `UPDATE "public"."<table>" SET <col>=$1, ... WHERE <pk>=$N, ...`
- MySQL stub: returns `fmt.Errorf("edit row not yet implemented for MySQL")`
- SQLite stub: same pattern
- Oracle stub: same pattern

**Error cases:**
- Empty `setColumns` → error
- Empty `whereColumns` → error (safety: must not update without a WHERE)
- Table doesn't exist → database error propagated
- Constraint violation → database error propagated

### Modal messages

```go
type editRowSavedMsg struct {
    session uint64
    err     error
}

type editRowOpenMsg struct {
    row    []any
    columns []db.Column
    table  db.Table

```

### Keybinding contract

- `e` key: only handled when `m.panel == panelData && m.focus == focusData && m.activeRelation.set && len(m.data.page.Rows) > 0 && !m.data.loading`
- When `m.editRowModal != nil`, `e` does nothing (modal captures all keys)

## 6. Behavior & states

### Edit row modal state machine

```
         ┌─────────┐
         │ editing │  ← open with fields pre-filled
         └────┬────┘
     Esc/     │  Enter (save)
    cancel    │
      │       ▼
      │   ┌─────────┐
      │   │ saving  │  ← spinner, fields disabled
      │   └────┬────┘
      │        │
      │   ┌────┴────┐
      │   │         │
      │   ▼         ▼
      │ success   failed
      │   │         │
      │   │ Enter   │ Enter/Esc
      │   │ or Esc  │
      │   ▼         ▼
      └──►┌─────────┐
          │ closed  │  ← modal dismissed, page reloaded
          └─────────┘
```

### Transitions

| State | Enter | Esc | Up/Down |
|-------|-------|-----|---------|
| editing | validate & save | close without saving | navigate fields |
| saving | (ignored) | (ignored) | (ignored) |
| success | close & reload | close & reload | (ignored) |
| failed | retry save | close | (ignored) |

### Validation rules (in `editing` state on Enter)

1. For each non-nullable field without a default: if the text input is empty, mark it as invalid
2. Validation errors shown inline below each field in red
3. If any validation fails, stay in `editing` state, don't transition to `saving`

### Null representation in the modal

| Original value | Input display | Sent to DB |
|---------------|---------------|------------|
| `nil` (NULL) | empty, placeholder "(NULL)" | `nil` (NULL) |
| `"hello"` | `"hello"` | `"hello"` |
| `123` | `"123"` | `"123"` |
| `nil` → user types "x" | `"x"` | `"x"` |
| `"hello"` → user clears | empty | `nil` (NULL) |

    New `listColumnsSQL`:
    ```sql
    SELECT
        attribute.attname AS column_name,
        row_number() OVER (ORDER BY attribute.attnum) AS ordinal_position,
        regexp_replace(
            regexp_replace(
                CASE type_catalog.typname
                    WHEN 'int2' THEN 'int2'
                    WHEN 'int4' THEN 'int4'
                    WHEN 'int8' THEN 'int8'
                    WHEN 'float4' THEN 'float4'
                    WHEN 'float8' THEN 'float8'
                    WHEN 'bool' THEN 'bool'
                    ELSE pg_catalog.format_type(attribute.atttypid, attribute.atttypmod)
                END,
                '^character varying',
                'varchar'
            ),
            '^character',
            'char'
        ) AS data_type,
        CASE attribute.attidentity
            WHEN 'a' THEN 'ALWAYS'
            WHEN 'd' THEN 'BY DEFAULT'
            ELSE NULL
        END AS identity,
        CASE
            WHEN attribute.attcollation = 0 THEN NULL
            WHEN attribute.attcollation = type_catalog.typcollation THEN 'default'
            ELSE quote_ident(collation_schema.nspname)
                 || '.'
                 || quote_ident(collation_catalog.collname)
        END AS collation_name,
        attribute.attnotnull AS not_null,
        pg_catalog.pg_get_expr(default_value.adbin, default_value.adrelid) AS default_expression,
        pg_catalog.col_description(attribute.attrelid, attribute.attnum) AS comment,
        COALESCE(pk.constraint_type IS NOT NULL, false) AS is_primary_key
    FROM pg_catalog.pg_attribute AS attribute
    JOIN pg_catalog.pg_class AS relation
        ON relation.oid = attribute.attrelid
    JOIN pg_catalog.pg_namespace AS relation_schema
        ON relation_schema.oid = relation.relnamespace
    JOIN pg_catalog.pg_type AS type_catalog
        ON type_catalog.oid = attribute.atttypid
    LEFT JOIN pg_catalog.pg_attrdef AS default_value
        ON default_value.adrelid = attribute.attrelid
       AND default_value.adnum = attribute.attnum
    LEFT JOIN pg_catalog.pg_collation AS collation_catalog
        ON collation_catalog.oid = attribute.attcollation
    LEFT JOIN pg_catalog.pg_namespace AS collation_schema
        ON collation_schema.oid = collation_catalog.collnamespace
    LEFT JOIN (
        SELECT conrelid, unnest(conkey) AS conkey_attnum, contype AS constraint_type
        FROM pg_catalog.pg_constraint
        WHERE contype = 'p'
    ) AS pk ON pk.conrelid = attribute.attrelid AND pk.conkey_attnum = attribute.attnum
    WHERE relation_schema.nspname = 'public'
      AND relation.relname = $1
      AND attribute.attnum > 0
      AND NOT attribute.attisdropped
    ORDER BY attribute.attnum
    ```

    ```go
    // UpdateRow updates a single row in a public PostgreSQL table.
    func (p *postgresql) UpdateRow(ctx context.Context, table db.Table, setColumns map[string]any, whereColumns map[string]any) error {
        if table.Name == "" {
            return errors.New("table name is required")
        }
        if len(setColumns) == 0 {
            return errors.New("no columns to set")
        }
        if len(whereColumns) == 0 {
            return errors.New("no WHERE columns; refusing to update without a WHERE clause")
        }

        tableIdent := pgx.Identifier{"public", table.Name}.Sanitize()

        setClauses := make([]string, 0, len(setColumns))
        args := make([]any, 0, len(setColumns)+len(whereColumns))
        argIdx := 1

        // Build SET clause (ordered by column name for determinism)
        setNames := make([]string, 0, len(setColumns))
        for name := range setColumns {
            setNames = append(setNames, name)
        }
        sort.Strings(setNames)
        for _, name := range setNames {
            setClauses = append(setClauses, fmt.Sprintf("%s = $%d", pgx.Identifier{name}.Sanitize(), argIdx))
            args = append(args, setColumns[name])
            argIdx++
        }

        // Build WHERE clause
        whereClauses := make([]string, 0, len(whereColumns))
        whereNames := make([]string, 0, len(whereColumns))
        for name := range whereColumns {
            whereNames = append(whereNames, name)
        }
        sort.Strings(whereNames)
        for _, name := range whereNames {
            if whereColumns[name] == nil {
                whereClauses = append(whereClauses, fmt.Sprintf("%s IS NULL", pgx.Identifier{name}.Sanitize()))
            } else {
                whereClauses = append(whereClauses, fmt.Sprintf("%s = $%d", pgx.Identifier{name}.Sanitize(), argIdx))
                args = append(args, whereColumns[name])
                argIdx++
            }
        }

        query := fmt.Sprintf("UPDATE %s SET %s WHERE %s",
            tableIdent,
            strings.Join(setClauses, ", "),
            strings.Join(whereClauses, " AND "),
        )

        p.logger.Log(query)
        tag, err := p.pool.Exec(ctx, query, args...)
        if err != nil {
            return fmt.Errorf("update PostgreSQL row: %w", err)
        }
        if tag.RowsAffected() == 0 {
            return errors.New("no row matched the WHERE clause; the row may have been modified or deleted")
        }
        return nil
    }
    ```

### Task 4 — Create the `editRowModal` type

- **Why:** New edit row modal following the existing modal pattern.
- **Files & changes:**

  - `internal/app/edit_row_modal.go` (new file):
    ```go
    package app

    import (
        "fmt"
        "strings"

        "charm.land/bubbles/v2/textinput"
        tea "charm.land/bubbletea/v2"
        "charm.land/lipgloss/v2"

        "github.com/ernestoponce27/db-tui/internal/db"
    )

    type editRowState uint8

    const (
        editRowEditing editRowState = iota
        editRowSaving
        editRowSuccess
        editRowFailed
    )

    type editRowField struct {
        column   db.Column
        input    textinput.Model
        original any
        errorMsg string // inline validation error for this field
    }

    type editRowModal struct {
        tableName string
        table     db.Table
        fields    []editRowField
        selected  int
        offset    int
        state     editRowState
        err       error
    }

    type editRowCancelMsg struct{}
    type editRowSaveMsg struct {
        table        db.Table
        setColumns   map[string]any
        whereColumns map[string]any
        session      uint64
    }

    func newEditRowModal(table db.Table, columns []db.Column, row []any) editRowModal {
        fields := make([]editRowField, 0, len(columns))
        for i, col := range columns {
            var value any
            if i < len(row) {
                value = row[i]
            }

            input := textinput.New()
            input.Prompt = ""
            input.SetWidth(50)
            if value != nil {
                input.SetValue(formatCell(value))
            } else {
                input.Placeholder = "(NULL)"
            }
            if col.Identity != "" {
                input.SetValue(formatCell(value))
                input.Blur() // read-only visually
            }

            fields = append(fields, editRowField{
                column:   col,
                input:    input,
                original: value,
            })
        }
        return editRowModal{
            tableName: table.Name,
            table:     table,
            fields:    fields,
            state:     editRowEditing,
        }
    }

    func (m editRowModal) update(msg tea.Msg) (editRowModal, tea.Cmd) {
        key, ok := msg.(tea.KeyPressMsg)
        if !ok {
            return m, nil
        }

        switch m.state {
        case editRowEditing:
            return m.updateEditing(key)
        case editRowSuccess, editRowFailed:
            switch key.String() {
            case "enter", "esc":
                return m, func() tea.Msg { return editRowCancelMsg{} }
            }
        }
        return m, nil
    }

    func (m editRowModal) updateEditing(key tea.KeyPressMsg) (editRowModal, tea.Cmd) {
        switch key.String() {
        case "esc":
            return m, func() tea.Msg { return editRowCancelMsg{} }
        case "enter":
            return m.submitSave()
        case "up", "k":
            if m.selected > 0 {
                m.selected--
                m.ensureFieldVisible(8) // reasonable visible field count
            }
        case "down", "j":
            if m.selected < len(m.fields)-1 {
                m.selected++
                m.ensureFieldVisible(8)
            }
        default:
            // Forward key to the currently selected field's input
            field := &m.fields[m.selected]
            var cmd tea.Cmd
            field.input, cmd = field.input.Update(key)
            return m, cmd
        }
        return m, nil
    }

    func (m *editRowModal) ensureFieldVisible(visibleFields int) {
        if m.selected < m.offset {
            m.offset = m.selected
        }
        if m.selected >= m.offset+visibleFields {
            m.offset = m.selected - visibleFields + 1
        }
    }

    func (m editRowModal) editableFields() []editRowField {
        out := make([]editRowField, 0, len(m.fields))
        for _, f := range m.fields {
            if f.column.Identity == "" {
                out = append(out, f)
            }
        }
        return out
    }

    func (m editRowModal) submitSave() (editRowModal, tea.Cmd) {
        // Validate
        hasError := false
        for i := range m.fields {
            f := &m.fields[i]
            f.errorMsg = ""
            if f.column.Identity != "" {
                continue // skip identity columns entirely
            }
            if f.column.NotNull && f.column.Default == "" && strings.TrimSpace(f.input.Value()) == "" {
                f.errorMsg = "not null"
                hasError = true
            }
        }
        if hasError {
            return m, nil
        }

        setColumns := make(map[string]any)
        whereColumns := make(map[string]any)

        for _, f := range m.fields {
            val := f.input.Value()
            // Determine if the value changed
            originalStr := ""
            if f.original != nil {
                originalStr = formatCell(f.original)
            }
            if f.column.Identity != "" {
                // Identity columns go to WHERE (original value) only
                if f.original == nil {
                    whereColumns[f.column.Name] = nil
                } else {
                    whereColumns[f.column.Name] = f.original
                }
                continue
            }

            // For SET: only include if changed
            if val != originalStr {
                if strings.TrimSpace(val) == "" {
                    setColumns[f.column.Name] = nil
                } else {
                    setColumns[f.column.Name] = val
                }
            }

            // For WHERE: use original value for PK columns (fallback: all columns)
            isPK := f.column.IsPrimaryKey
            // If no PKs at all, use all non-identity original values as WHERE
            hasAnyPK := false
            for _, ff := range m.fields {
                if ff.column.IsPrimaryKey {
                    hasAnyPK = true
                    break
                }
            }
            if isPK || !hasAnyPK {
                if f.original == nil {
                    whereColumns[f.column.Name] = nil
                } else {
                    whereColumns[f.column.Name] = f.original
                }
            }
        }

        if len(setColumns) == 0 {
            // Nothing changed; treat as cancel
            return m, func() tea.Msg { return editRowCancelMsg{} }
        }

        m.state = editRowSaving
        return m, func() tea.Msg {
            return editRowSaveMsg{
                table:        m.table,
                setColumns:   setColumns,
                whereColumns: whereColumns,
            }
        }
    }

    func (m editRowModal) view(width int) string {
        switch m.state {
        case editRowEditing:
            return m.viewEditing(width)
        case editRowSaving:
            return m.viewSaving(width)
        case editRowSuccess:
            return m.viewResult(width, "✓ Row updated", "86")
        case editRowFailed:
            return m.viewResult(width, "✕ "+sanitizeText(m.err.Error()), "203")
        }
        return ""
    }

    func (m editRowModal) viewEditing(width int) string {
        modalWidth := min(70, max(50, width-8))
        boldStyle := lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("230"))
        labelStyle := lipgloss.NewStyle().Foreground(lipgloss.Color("86")).Width(20)
        errorStyle := lipgloss.NewStyle().Foreground(lipgloss.Color("203"))
        dimStyle := lipgloss.NewStyle().Foreground(lipgloss.Color("245"))

        lines := []string{
            boldStyle.Render("Edit row — " + sanitizeText(m.tableName)),
            "",
            dimStyle.Render("↑/↓ navigate  •  Enter save  •  Esc cancel"),
            "",
        }

        visibleFields := 8
        lastField := min(m.offset+visibleFields, len(m.fields))
        for i := m.offset; i < lastField; i++ {
            f := m.fields[i]
            prefix := "  "
            if i == m.selected {
                prefix = "> "
            }

            label := f.column.Name
            if f.column.IsPrimaryKey {
                label += " (PK)"
            }
            if f.column.Identity != "" {
                label += " (identity)"
            }
            if f.column.NotNull {
                label += " *"
            }
            typeInfo := dimStyle.Render(" " + f.column.DataType)

            lines = append(lines, prefix+labelStyle.Render(truncateLabel(label, 18))+typeInfo)
            if f.column.Identity != "" {
                lines = append(lines, "  "+dimStyle.Render(f.input.Value()+" (read-only)"))
            } else {
                lines = append(lines, "  "+f.input.View())
            }
            if f.errorMsg != "" {
                lines = append(lines, "  "+errorStyle.Render("✕ "+f.errorMsg))
            }
        }

        if lastField < len(m.fields) {
            lines = append(lines, dimStyle.Render(fmt.Sprintf("  … %d more fields", len(m.fields)-lastField)))
        }

        return lipgloss.NewStyle().
            Width(modalWidth).
            MaxHeight(20).
            Padding(1, 2).
            Border(lipgloss.RoundedBorder()).
            BorderForeground(lipgloss.Color("62")).
            Background(lipgloss.Color("235")).
            Render(strings.Join(lines, "\n"))
    }

    func (m editRowModal) viewSaving(width int) string {
        return m.viewResult(width, "Saving…", "86")
    }

    func (m editRowModal) viewResult(width int, message, color string) string {
        modalWidth := min(50, max(40, width-8))
        lines := []string{
            lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("230")).Render("Edit row — " + sanitizeText(m.tableName)),
            "",

        }
        if m.state == editRowFailed || m.state == editRowSuccess {

            Width(modalWidth).
    ```

## 10. Risks & open items

- **Fallback WHERE behavior:** If a table has no primary key, all non-identity original column values are used in the WHERE clause. If two rows happen to have identical values across all those columns, both would be updated. This is a rare edge case documented here. A future improvement could use `ctid` for PostgreSQL or `rowid` for SQLite as a more reliable fallback.
- **Type parsing:** Text input values are sent as strings. The PostgreSQL driver relies on PostgreSQL's implicit type coercion (e.g., a string `"123"` becomes an integer via `$1` parameter). For most types this works, but for complex types (arrays, JSON, etc.) the text representation must match what PostgreSQL expects. This is acceptable for an initial version.
- **Large rows:** Rows with many columns produce a tall modal. The modal is capped at 20 lines and scrolls via `↑/↓`. This is acceptable for MVP.
- **Concurrent modification:** If another session modifies the row between loading and saving, the UPDATE may affect zero rows (if PK changed) or overwrite silently (if non-PK values changed). The "zero rows affected" case is handled with an error message. Full optimistic locking is out of scope.
